#  Hospital Management System

A MySQL-based database project that manages core hospital operations — patients, doctors, admissions, prescriptions, and billing.

---

##  What it does

- Register patients and maintain their medical records
- Manage doctors and nurses under a staff hierarchy
- Allocate beds and track admissions with real-time availability
- Schedule doctor appointments without time-slot conflicts
- Handle multi-medicine prescriptions
- Auto-generate bills for every admission

---

##  Tech Used

- **Database:** MySQL
- **Language:** SQL

---

##  How to Run

```bash
mysql -u root -p < hms_schema.sql
```

Or open `hms_schema.sql` in MySQL Workbench and run it.
